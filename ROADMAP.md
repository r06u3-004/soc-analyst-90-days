# SOC Analyst — 90-Day Roadmap

## Program Overview

This roadmap defines a structured 90-day practical learning program focused on developing operational skills for a Security Operations Center (SOC) Analyst Level 1 position.

The program emphasizes security monitoring, log analysis, alert triage, threat detection, incident investigation and incident response.

Learning activities combine technical documentation, online cybersecurity platforms, practical investigations and security tools.

---

## Phase 1 — SOC Fundamentals and Security Operations

**Days 01–15**

### Objectives
- Understand SOC architecture, roles and responsibilities.
- Understand security monitoring and alert management.
- Review essential networking and cybersecurity concepts.
- Understand common attack techniques and security events.
- Become familiar with the incident management lifecycle.

### Topics
- SOC operations and workflows
- SOC Analyst L1 responsibilities
- Security events, alerts and incidents
- TCP/IP, DNS, HTTP/HTTPS
- Common network protocols
- Cybersecurity fundamentals
- MITRE ATT&CK framework
- Incident response lifecycle

### Expected Deliverables
- SOC operations notes
- Network fundamentals documentation
- Security event classification notes
- MITRE ATT&CK overview

## Final Assessment — Day 90

At the end of the program, a practical assessment will evaluate the ability to:

- Analyze and prioritize security alerts.
- Investigate suspicious events using logs and network evidence.
- Identify and validate Indicators of Compromise.
- Correlate security events.
- Apply MITRE ATT&CK techniques.
- Produce structured incident investigation reports.
- Recommend appropriate incident response actions.

## Learning Principles

1. Prioritize practical exercises over passive learning.
2. Document every significant investigation.
3. Explain the reasoning behind each finding.
4. Distinguish confirmed evidence from assumptions.
5. Use authorized environments and datasets.
6. Review and improve investigation methodologies continuously.
