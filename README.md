# SOC Analyst — 90-Day Journey

**A Practical Journey in Security Operations, Threat Detection and Incident Response**

## Overview

This repository documents a structured 90-day practical learning journey focused on Security Operations Center (SOC) operations and defensive cybersecurity.

It serves as a technical portfolio showcasing practical exercises, security investigations, SIEM analysis, threat detection techniques, incident response procedures and digital forensics.

The primary objective is to strengthen operational SOC Analyst L1 capabilities through hands-on labs, realistic security scenarios and structured technical documentation.

## Learning Objectives

- Understand SOC operations, monitoring workflows and alert management.
- Analyze security events and investigate suspicious activities.
- Perform security alert triage and incident investigations.
- Develop practical experience with SIEM solutions.
- Analyze network traffic and identify malicious behavior.
- Perform threat intelligence and Indicators of Compromise (IOC) analysis.
- Apply incident response methodologies.
- Develop threat hunting capabilities.
- Use the MITRE ATT&CK framework to contextualize adversary techniques.
- Produce structured technical investigation reports.

## 90-Day Roadmap

| Period | Focus Area | Key Topics |
|---|---|---|
| Days 01–15 | SOC Fundamentals | SOC operations, security concepts, networking |
| Days 16–30 | Log and Network Analysis | Windows Event Logs, Linux logs, Wireshark |
| Days 31–45 | SIEM Operations | Splunk, Wazuh, Elastic Security |
| Days 46–60 | Threat Intelligence | IOC analysis, OSINT, threat feeds |
| Days 61–75 | Incident Response | Alert triage, investigation, containment |
| Days 76–90 | Threat Hunting and DFIR | Threat hunting, digital forensics, investigations |

4. Evidence and observations
